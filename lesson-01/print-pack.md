## ② 자·모 결합 원리 시트 (학생 배포용)

### 규칙 3가지

**1. 세로 모음** — 자음은 왼쪽

```
ㅏ ㅑ ㅓ ㅕ ㅣ ㅐ ㅔ ㅒ ㅖ
```

예:
- 가 (ㄱ+ㅏ)  ·  겨 (ㄱ+ㅕ)  ·  니 (ㄴ+ㅣ)  ·  매 (ㅁ+ㅐ)  ·  페 (ㅍ+ㅔ)

**2. 가로 모음** — 자음은 위

```
ㅗ ㅛ ㅜ ㅠ ㅡ
```

예:
- 고 (ㄱ+ㅗ)  ·  뉴 (ㄴ+ㅠ)  ·  두 (ㄷ+ㅜ)  ·  므 (ㅁ+ㅡ)  ·  쥬 (ㅈ+ㅠ)

**3. 복모음** — 자음은 왼쪽 위

```
ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ
```

예:
- 봐 (ㅂ+ㅘ)  ·  뭐 (ㅁ+ㅝ)  ·  외 (ㅇ+ㅚ)  ·  뷔 (ㅂ+ㅟ)  ·  의 (ㅇ+ㅢ)

### 함께 외울 것 (한 줄만)

> **"모음 방향이 자음 위치를 정한다.**
> **세로면 왼쪽, 가로면 위, 복잡하면 왼쪽 위."**
