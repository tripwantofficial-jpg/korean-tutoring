# Korean Tutoring · 한국어 과외 자료

4주 한글 리터러시 부트캠프 + 이어지는 커리큘럼용 수업 자료 저장소.

## 🎴 자모·단어 플래시카드 (라이브)

**바로 열기**: [https://tripwantofficial-jpg.github.io/korean-tutoring/lesson-01/flashcards.html](https://tripwantofficial-jpg.github.io/korean-tutoring/lesson-01/flashcards.html)

- 자모 40장 + 기초단어 100장, 3개 모드 (진단 · 연습 · 역방향)
- 오답 자동 리뷰 → 재훈련 라운드 → 완주 축하 흐름
- 태블릿·폰 반응형. 라이트/다크 자동

## 📁 폴더 구조

```
korean-tutoring/
├── literacy-bootcamp-4week.md   ← 4주 부트캠프 전체 커리큘럼
└── lesson-01/                   ← 1회차 수업 자료
    ├── lesson-plan.md            강사용 120분 진행 대본
    ├── print-pack.md             인쇄 자료 (자모 카드·음절표·기록지)
    ├── syllable-sheets-A-B.md    화·금 속도 읽기 시트
    ├── dictation-scripts.md      받아쓰기 스크립트 (강사 전용)
    ├── week-1-homework.md        학생용 첫 주 숙제 팩
    └── flashcards.html           자모·단어 플래시카드 웹앱
```

## 사용 흐름

1. **수업 태블릿**에서 플래시카드 URL 열기 → "학생 진단" 모드
2. **학생 폰**에도 같은 URL 카톡으로 전달 → 매일 15분 "혼자 연습"
3. 종이 자료는 `lesson-01/*.md` 를 PDF로 변환해 사용
